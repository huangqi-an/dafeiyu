dafeiyu playground

本页通过 <script src="/dist/dafeiyu.iife.js"> 加载 IIFE 产物，素材走仓库根的 /assets/——与 CDN 用户的接入方式一致。先 npm run build，再 npm run serve 打开本页。

容器是 Shadow DOM，宿主页面样式进不去，宠物观感在任何站点一致。气泡、视频、拖拽物理都在里面。段落文字是给你拖着鱼遮挡/对照用的。文本可以随便滚，验证宠物 fixed 定位与页面滚动互不干扰。

透明视频在浅色与深色底上都应正常融合——用「切换底色」验证边缘没有黑底（Safari 黑底问题只在本机是 macOS WebKit 时出现，此时应自动改用 .mov 素材）。

耗一下时间看行为：待机会在呼吸/哼歌/张望/哈欠之间切换（深夜哈欠更多）；偶发横着走两步；约 2% 概率「蓝鲸现世」；5 分钟无操作睡着，点击惊醒；连点 5 次它会生气。

填充段落：网页宠物的意义在于陪伴感与一点惊喜。大肥鱼游过你的文章列表，偶尔冒个泡，提醒你喝水、休息、别和 bug 置气。

填充段落：dafeiyu 是零依赖的原生实现，挂载后只增加一个 fixed 容器与一个 video 元素；页面不可见时它会把动画与定时器全部挂起，不空耗电。
